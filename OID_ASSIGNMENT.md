# OID assignment record

Every canonical resource in this IG (CodeSystem, ValueSet, ConceptMap,
StructureDefinition, Library, Measure) carries an OID, published as
`identifier = urn:oid:…`, for use by OID-based systems such as CDA.
The OIDs are technical identity metadata only. They do not imply any HL7,
government, NTUCC or clinical endorsement.

| Item | Value |
|---|---|
| Canonical URL | `https://healthymind-tech.github.io/ntucc-fhir-colorectal-cancer-ig` |
| Derivation | UUIDv5 with the standard URL namespace and the exact canonical URL |
| UUID | `6ad99241-6c93-540f-af20-2ba63727ce83` |
| OID root | `2.25.142027862386738326818551980187783253635` |
| Register | `ig/oids.ini` (generated by the IG Publisher, committed) |

The `2.25` arc (ISO/IEC 9834-8, ITU-T X.667) turns a UUID into an OID that is
globally unique without any registration authority, so this root claims no
organisational OID allocation. The IG Publisher documents that `auto-oid-root`
may be self-assigned and that the generated `oids.ini` must be committed.

## Rules

1. The root is derived from the exact canonical URL above. Changing the
   canonical URL does **not** authorise changing the root.
2. An OID, once assigned, is never reassigned. If a resource is retired, its
   line stays in `ig/oids.ini` so the OID is not reused.
3. When a new canonical resource is added, run `scripts/build_ig.sh`; the
   Publisher appends the new assignment to `ig/oids.ini`. Commit it. CI fails
   if a build would assign an OID that is not committed.

## Registration (not pursued)

The IG Publisher warns that the root is not registered in the FHIR IG registry
(`oid-assignments.json` in <https://github.com/FHIR/ig-registry>). Registering
would be a pull request to that external repository.

Decision (2026-11-24): registration is not pursued for now. The `2.25` root is
globally unique without registration, so the OIDs are valid and usable; the
registry entry is only a discoverability and governance step. The warning is
kept visible and deliberately **not** suppressed, so it can be revisited before
a formal release.
